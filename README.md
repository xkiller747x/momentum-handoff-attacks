# Momentum hand-off and switch timing in two-stage feature fine-tuning

Code and per-image evaluation records for the paper

> Yukun Lin. *Momentum hand-off and switch timing: Two hidden design choices in two-stage feature fine-tuning for targeted transfer attacks.* Submitted to Pattern Recognition Letters, 2026.

Two-stage targeted transfer attacks (ILA, FFT, AaF) run a baseline iterative attack and then fine-tune the adversarial example on an intermediate-layer objective. Their public implementations reset the optimizer momentum at the switch. This repository measures the cost of that reset, the trade-off it creates, and how it interacts with the switch iteration.

## Contents

| Path | What it contains |
|---|---|
| `main.py`, `baseline.py` | Command-line entry points (same sub-commands; see `python baseline.py -h`) |
| `utils/`, `baseline/` | Data handling, models, attacks (`baseline/feature_finetuning.py` implements FFT, AaF, ILA and the matched controls) |
| `test/` | CPU unit tests; no model weights or images needed |
| `results/<experiment>/` | Per-image evaluation records (`eval_*/progress.jsonl`), run configurations, summaries, exact commands (`logs/commands.txt`, `logs/eval_commands.txt`) and the report of each experiment |
| `results/*_plan_v1.md`, `results/holdout_protocol_v1.md` | Plans written before each experiment and the pre-registered hold-out protocol |

Adversarial images, float arrays and saved momenta are not included (several GB); they are regenerated by the commands. The experiment reports (`report.md`) and plans are written in Chinese; all numbers in the paper can be recomputed from the JSON records.

## Setup

Tested with Python 3.13, PyTorch 2.11 (CUDA 12.8), torchvision 0.26, NumPy 2.4, Pillow and Matplotlib 3.11.

```bash
pip install -r requirements.txt
python -m unittest discover -s test
```

Tests that compare against third-party reference code are skipped when the reference snapshot is not present (see *Third-party code* below).

### Data

The 1,000 ImageNet-compatible images of the NIPS 2017 adversarial competition with their target labels, as distributed by [TransferAttack](https://github.com/Trustworthy-AI-Group/TransferAttack) (follow the data link in its README; `data.zip`, SHA-256 `61cda9c03474f390d27a6c3db10f61337d5774bb364ab9eb2a9102f415cdaf6d`). Unpack it so that the images are in `data/raw/images/` and the labels in `data/raw/labels.csv`, then build the manifests:

```bash
python main.py prepare --images-dir data/raw/images --labels-csv data/raw/labels.csv --label-offset 0 --output data/canonical224
python main.py original299-prepare --manifest data/canonical224/manifest.json --output data/original299
```

The split (pilot 24, development 276, hold-out 700) is fixed by seed 20261027 and stored in the manifest.

### Model weights

Weights are not downloaded automatically. Place the official torchvision checkpoints in `data/models/torch/hub/checkpoints/`:
`resnet50-0676ba61.pth` (ResNet-50 V1), `densenet121-a639ec97.pth`, `vgg16_bn-6c64b313.pth`, `inception_v3_google-0cc3c7bd.pth` and `vit_b_16-c867db91.pth`, all from `https://download.pytorch.org/models/`.

## Reproducing an experiment

Every experiment directory lists its exact commands in `logs/commands.txt` (attacks) and `logs/eval_commands.txt` (evaluation). Each line has the form `name: baseline.py <arguments>`; run the part after the colon with Python from the repository root. Deterministic CUDA execution requires

```bash
export CUBLAS_WORKSPACE_CONFIG=:4096:8
```

Runs are bit-for-bit reproducible on the same hardware and software stack. Evaluation outputs (`eval_*/progress.jsonl`) contain, for every image and target model, the prediction, targeted success and target log-odds used in the paper.

Figures are rendered from the saved records with

```bash
python baseline.py paper-figures
```

Fig. 1 additionally needs the adversarial images of `results/feature_dev276_v1/aaf` and `results/fine_continue_dev276_v1/aaf_continue`, which are regenerated by the commands in those directories.

## Third-party code

The attack implementations are local re-implementations. Some follow MIT-licensed code (TransferAttack, OPS, FTM); their licenses are in `test/reference/`. Reference snapshots of FFT, AaF, CFM and RaPA author code, used only by tests that check numerical agreement, are not distributed because those repositories do not state a license; `test/reference/*SOURCES.md` and `baseline/SOURCES.md` list the exact upstream commits.
